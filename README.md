# Priyanshu Singh - Personal Portfolio

A modern, responsive personal portfolio website showcasing projects, skills, and services. Built with HTML, CSS, and vanilla JavaScript.

[![Visit Portfolio](https://img.shields.io/badge/%20Visit%20Portfolio-0066ff?style=for-the-badge&labelColor=1f6feb&color=0066ff)](https://priyanshu04295-glitch.github.io/portfolio_me/)


## 🌟 Features

- **Responsive Design** - Fully responsive layout that works on desktop, tablet, and mobile devices
- **Smooth Animations** - Scroll reveal animations and interactive hover effects
- **Typing Effect** - Dynamic typing animation for role description
- **Tab Navigation** - Interactive tabs for skills, experience, and education
- **Mobile Menu** - Hamburger menu for seamless mobile navigation
- **Service Cards** - Showcase your services with hover effects
- **Portfolio Grid** - Elegant portfolio grid with overlay effects
- **Contact Section** - Social media links and CV download
- **Modern UI** - Clean and professional design with gradient backgrounds

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/priyanshu04295-glitch/portfolio_me.git
cd portfolio_me
```

2. Add your assets:
   - Place images in `assets/images/`
   - Place your CV in `assets/documents/CV.pdf`

3. Customize the content by editing `index.html`

4. Open `index.html` in your browser or use a local server

## ✏️ Customization

- **Content**: Edit `index.html` to update your name, bio, skills, projects, and experience
- **Styling**: Modify `css/style.css` to change colors, fonts, and spacing
- **Animations**: Update `js/script.js` to customize the typing effect and other interactions
